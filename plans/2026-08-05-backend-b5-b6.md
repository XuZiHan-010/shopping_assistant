# B5 回答审核与 B6 反馈导出 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现可信数据回答、图表、独立 Reviewer、商家反馈和带 HMAC 签名的动态 CSV 导出。

**Architecture:** B5 在 LangGraph 中以 `QueryResult` 为唯一数据事实来源，先确定图表、再编排结构化回答、局部校验与独立审核，最多两轮。B6 将 DETAIL 的 `ExportSpec` 在 ChatService 中持久化为导出记录，下载时重新执行受控明细查询；反馈和导出均强制商家隔离或签名归属验证。

**Tech Stack:** Python 3.12、FastAPI、Pydantic v2、SQLAlchemy Async、PostgreSQL、Alembic、httpx、pytest、Ruff、mypy。

## Global Constraints

- 面向用户的内容使用中文；品牌一律使用 Borough。
- `deepseek-v4-flash` 是唯一真实模型；测试一律使用 Fake LLM，不得产生费用。
- LLM 不生成或执行 SQL；表、列、值、范围和商家范围继续由 B4 的受控服务决定。
- 所有数据访问按可信 `merchant_id` 隔离；跨商家访问须返回 403 并审计。
- `GET /api/exports/{id}` 只使用 HMAC URL 鉴权，签名覆盖 export_id、merchant_id、过期时间；链接有效期 15 分钟。
- 真实密钥只能来自环境变量；新增 `EXPORT_SIGNING_SECRET`，不复用 LLM 或管理员密钥。
- 未获得额外发布许可，不执行 Git commit、push、tag 或 PR。

```python
def build(self, result: QueryResult, metric: MetricPayload | None) -> Visualization:
    if not result.rows or metric is None:
        return Visualization(enabled=False)
    keys = {column.key for column in result.columns}
    dimension = "date" if "date" in keys else next((key for key in keys if key != metric.metric_code), None)
    if dimension is None or metric.metric_code not in keys:
        return Visualization(enabled=False)
    chart_type = ChartType.LINE if dimension == "date" else ChartType.BAR
    return Visualization(enabled=True, type=chart_type, allowed_types=[chart_type], dimension_key=dimension, metric_key=metric.metric_code, unit=metric.unit, data=_chart_rows(result.rows, dimension, metric.metric_code))
```

```python
class AnswerDraft(BaseModel):
    answer: Annotated[str, StringConstraints(min_length=1, max_length=4000)]
    recommendations: list[Recommendation] = Field(min_length=2, max_length=5)

async def compose(self, facts: AnswerFacts, llm: LlmClient, budget: LlmBudget) -> AnswerDraftResult:
    fallback = self._fallback(facts)
    try:
        result = await llm.complete(system=ANSWER_SYSTEM_PROMPT, user=facts.model_dump_json(), fallback=fallback.model_dump_json(), budget=budget)
        draft = AnswerDraft.model_validate_json(result.text)
        self._validate(draft, facts)
    except (ValueError, LlmUnavailableError, LlmBudgetExceededError):
        return AnswerDraftResult(draft=fallback, degraded=True, notes=["回答生成已降级为受控数据摘要。"])
    return AnswerDraftResult(draft=draft, degraded=result.degraded, notes=[])
```

```python
def _signature_payload(export_id: UUID, merchant_id: UUID, expires_at: int) -> bytes:
    return f"{export_id}:{merchant_id}:{expires_at}".encode("utf-8")

def _escape_cell(value: object) -> str:
    text = "" if value is None else str(value)
    return "'" + text if text.startswith(("=", "+", "-", "@")) else text
```
