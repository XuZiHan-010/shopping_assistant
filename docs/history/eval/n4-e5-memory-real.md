> 结论：**抽取模型选定 `deepseek-flash`。** 错误写入率 5%（2/40，均出自 1 条「更正」类用例），
> 20 条不应写入的用例（敏感信息诱导、助手推测、泛泛确认等）零误写。

- 用户于 2026-09-30 授权；接口 DeepSeek OpenAI 兼容接口，经 `build_guarded_llm`（`purpose=MEMORY`，每日预算熔断）；

- 实际用量（`llm_usage` 账本）：**40 次调用全部成功，输入 7,613 + 输出 1,118 = 8,731 token**，申请上限为 40 次 / 16 万 token；
- 数据库：本地可丢弃库 `borough_e5_real_test`（compose PostgreSQL 55432），未触及生产数据。
- 首次运行在连库时因 Windows 事件循环失败，`llm_usage` 为 0 行、未发生模型调用；补 `configure_event_loop_policy()` 后重跑。

## 结果

| 指标 | 值 |
| --- | --- |
| 用例 | 40（应写入 20、不应写入 20） |
| 正确写入 | 19 |
| 错误写入（选型首要指标） | 2 → **错误写入率 5%** |
| 漏记 | 0 |
| 精确率 | 0.905 |
| 失败用例 | MEM-016 |

MEM-016 原话「这次我要彩色款，以前喜欢素色」，期望只记一条「这次我要彩色款」，模型写了两条、均未与期望字面一致。
自动评分只做字面匹配，更正类与近义事实需人工复核；且「这次」是一次性需求，是否应沉淀为长期偏好本身存疑。
该类用例是后续提示词改进的重点（区分一次性需求与稳定偏好、更正时只保留新值）。
