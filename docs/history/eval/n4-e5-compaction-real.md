## 发现与处理

1. **锚点里数值与定义版本关联不上**（两种策略都受影响）：锚点把「工具来源（带数值，按 `工具#call_id`）」与「数据截至时间（带定义版本，按指标名）」
   分段列出，模型无法确认 1079.19 按哪个版本算。**已修复**：截至时间行带上同一个 `[工具#call_id]`（`anchors.py`，单测先红后绿）。
2. **正文里出现 DeepSeek 内部工具调用标记**（`<｜｜DSML｜｜ calls>…`）：不给工具时模型把调用语法写进正文。循环的质量重写同样不给工具，
   线上可能把这段标记当回答展示。**已修复**：`runner.py` 识别该标记后按上游异常可见降级（R7），正常作答与质量重写两条路径各一条测试。
3. **模型把围栏 ID 当草稿编号**（m12）：围栏标记里的 16 位随机 ID 被当作编号输出。未改代码：真实循环里这类无来源数字会被确定性校验拦下并重写；
   如需根治，可改为不含数字的围栏 ID，属后续评估项。

在本评测里没有转化为更好的回答。修复 1、2 之后未重跑真实对比（超出本次授权）；如需验证修复效果须另行授权（约 90 次、约 40 万 token）。
