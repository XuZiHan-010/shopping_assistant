# 项目进度快照设计

## 目标

为跨日工作的 coding agent 提供一个无需翻阅完整历史即可继续开发的外部记忆入口。

## 设计

新增 `docs/project-progress.md`，只维护一份当前快照，并在顶部标记最后更新日期。快照固定包含当前阶段、已完成、验证结果、下一步、风险/阻塞和关键入口；不保留按日追加日志，历史由版本控制或会话记录承担。

`AGENTS.md` 将该文件列入当前已有文档、目标目录和开工必读顺序，并规定每次完成一段可验证工作后更新快照。

## 验收

- 新 agent 读取 `AGENTS.md` 后能发现并读取项目进度快照。
- 快照明确说明已完成阶段、可复现的验证结果和下一步。
- 快照顶部包含最后更新日期，且不会累积成按日流水账。
